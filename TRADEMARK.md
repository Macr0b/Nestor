# Nom et logo Nestor / Nestor name and logo

## Français

Le nom **« Nestor »** (comme nom de ce logiciel), le logo (le N en pièces de bois) et le mot « Nestor » dessiné en pièces découpées appartiennent à Macr0b. Ils **ne sont pas couverts** par la licence du code (fichier `LICENSE`).

Ce qui est permis sans demander :

- utiliser Nestor tel quel, avec son nom et son logo, y compris pour un usage professionnel ;
- parler de Nestor, le citer ou indiquer qu'un fichier ou un outil est « compatible avec Nestor ».

Ce qui demande une autorisation écrite :

- utiliser le nom « Nestor » ou les logos pour une version modifiée, un autre logiciel, un service ou un produit ;
- utiliser un nom ou un logo assez proche pour créer une confusion avec Nestor.

Une version modifiée doit donc porter un autre nom et un autre logo, et ne pas laisser croire qu'elle vient de l'auteur de Nestor.

Fichiers concernés : `icons/`, le titre dessiné dans `index.html`, et toute autre représentation du logo.

Allowed without asking:

- using Nestor as is, with its name and logo, including for professional work;
- talking about Nestor, quoting it, or stating that a file or tool is "compatible with Nestor".

Requires written permission:

- using the name "Nestor" or the logos for a modified version, another software, a service or a product;
- using a name or logo close enough to be confused with Nestor.

A modified version must therefore use another name and another logo, and must not suggest that it comes from the author of Nestor.

Files concerned: `icons/`, the drawn title in `index.html`, and any other rendering of the logo.
